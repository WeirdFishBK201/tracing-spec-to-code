# Tracing Spec to Code

This context defines the authorization language used to move a traced
requirement from agreement through implementation and controlled change.

## Language

**Requirements Confirmation**:
The user's explicit agreement that the documented product outcome, constraints,
and acceptance criteria are the facts to implement.
_Avoid_: Requirement approval, specification approval

**Implementation Approval**:
The user's explicit authorization to execute the current milestone plan.
_Avoid_: Planning approval, milestone permission

**Change Approval**:
The user's explicit authorization to apply a material change to previously
confirmed requirements or an approved milestone plan.
_Avoid_: Exception approval, deviation permission

**Change Request**:
The maintained project record that describes a proposed material change, its
impact, and the decision governing it.
_Avoid_: Exception note, amendment memo
